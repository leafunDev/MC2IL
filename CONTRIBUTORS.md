# MC2IL contributors

This file recognizes people whose accepted work has been merged into MC2IL. The maintainer updates it after reviewing and merging a pull request.

GitHub also builds an automatic contributor graph under Insights → Contributors. GitHub attributes qualifying commits on the default branch when the commit author email is linked to a GitHub account. This file tracks contributors recognized for work on MC2IL.

No additional MC2IL contributors have been recorded yet. Copyright and license notices are documented in [LICENSE](LICENSE) and [NOTICE](NOTICE).
