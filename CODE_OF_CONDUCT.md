# Code of Conduct

MC2IL project spaces are for respectful, focused collaboration. Treat people with respect, discuss technical disagreements without personal attacks, and avoid harassment, discrimination, threats, doxxing, and repeated disruption.

This policy applies to project issues, pull requests, discussions, and other spaces used to represent MC2IL.

Maintainers may edit or remove unacceptable content, close discussions or pull requests, and restrict participation when needed to keep the project usable. To report a conduct concern, contact the maintainer using the contact information on the [maintainer's GitHub profile](https://github.com/leafunDev). Do not include private or sensitive details in a public issue. For security reports, follow [SECURITY.md](SECURITY.md).
