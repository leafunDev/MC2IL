# MC2IL 1.0.0 Preview 1

This is the first public preview of MC2IL, a tool for analyzing Unity IL2CPP builds and reconstructing managed assemblies with recovered method bodies.

## Downloads

Each platform archive contains a self-contained .NET 10 command-line executable, the optional plugin assemblies, the project README, and the applicable license and notice files. No separate .NET runtime installation is required.

Available targets: Windows x64 and ARM64, Linux x64 and ARM64, and macOS x64 and ARM64. SHA-256 hashes for the archives are provided in `SHA256SUMS.txt`.

Extract an archive and run MC2IL from its extracted directory so it can find the bundled `Plugins` folder:

- Windows: `MC2IL.exe --list-output-formats`
- Linux or macOS: `./MC2IL --list-output-formats`

## Preview status

Method-body recovery is experimental. Some generated methods may contain unresolved native values or incomplete control flow. Results vary with the Unity version, architecture, and native binary; review recovered output before relying on it.

This release is intended for evaluation and feedback. It does not include or distribute game APKs or other game assets.
