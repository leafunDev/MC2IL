# Support

Before opening a request, check the [README](README.md), existing issues, and the relevant project documentation.

- **Bug or incorrect output:** open an issue with the Bug report template. Include the MC2IL version, operating system, Unity version if known, target architecture, output format, and the smallest useful log excerpt.
- **Feature request:** use the Feature request template and describe the problem the change should solve.
- **Usage question:** use the Usage question template and include the command, expected result, and actual result.
- **Security issue:** use the private reporting process in [SECURITY.md](SECURITY.md). Do not post vulnerability details in a public issue.

Do not upload APKs, game binaries, metadata, or other files unless you have permission to share them. Redact personal paths, account names, and tokens from logs.
